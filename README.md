## Что загрузить на GitHub Pages

Загрузи в корень репозитория BOOKED эти файлы:

- `index.html`
- `config.js`
- `README.md`

Важно: загружай именно файлы из архива, а не сам ZIP.

После `Commit changes` открой сайт так:

```text
https://bannikov07v-prog.github.io/BOOKED/?v=goldsize
```

Если видишь блок `Заявки идут в @goldsize`, значит обновление встало правильно.
