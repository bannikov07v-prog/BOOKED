# BOOKED — готовый лендинг + Telegram-заявки

Что уже сделано:

- полностью переделан дизайн главной страницы;
- добавлены анимации, карточки, блоки доверия, FAQ и тарифы;
- калькулятор считает примерную недополученную выручку;
- форма готова отправлять заявки в backend и Telegram-бота;
- если backend ещё не размещён, сайт открывает Telegram-бота и копирует текст заявки;
- блок оплаты подготовлен под платёжные ссылки.

## Как включить реальные платежи

1. Зарегистрируй платёжный сервис: ЮKassa, CloudPayments, Robokassa или другой.
2. Создай платёжные ссылки для тарифов:
   - «Разбор + план»;
   - «Настройка BOOKED».
3. Открой `config.js` и вставь ссылки:

```js
paymentLinks: {
  audit: "https://...",
  setup: "https://..."
}
```

Ключи платёжной системы нельзя вставлять в `index.html`, потому что сайт лежит публично на GitHub Pages. Для старта используй платёжные ссылки. Если потом нужна полноценная API-оплата, её нужно делать через backend.

## Как подключить Telegram-бота

1. Перейди в папку `backend`.
2. Создай `.env` по примеру `.env.example`.
3. Вставь `BOT_TOKEN` от BotFather.
4. Запусти backend.
5. Напиши боту `/start` с аккаунта владельца.
6. Размести backend на сервере и вставь его HTTPS-адрес в `config.js`:

```js
backendUrl: "https://your-backend-url.com"
```

Пока `backendUrl` пустой, форма будет работать через Telegram-переход и копирование заявки.

## Что заливать на GitHub Pages

Для сайта нужны:

- `index.html`
- `config.js`

Папку `backend` не заливай на GitHub Pages вместе с `.env`. Backend нужно размещать отдельно на сервере.
